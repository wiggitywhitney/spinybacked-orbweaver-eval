## Key Decisions

- **Add `set -o pipefail` to template instrument command** — Prevents crashed instrumentation from being masked as success by the `tee` command.

- **Force-add run log with `git add -f`** — Runs 1–4 lost their logs to the repository's `*.log` ignore rule; explicit force-add ensures logs are committed.

- **Read SCH-003 attribute types from OTLP export, not Datadog** — Datadog renders boolean attributes as quoted strings, making them indistinguishable from actual string values; OTLP traces show the true type.

- **Establish standing scoring readings for per-file evaluation** — Formalized a set of interpretation guidelines for scoring rules where the research rubric has drifted from implementation, allowing evaluators to make consistent calls without approval pauses.

- **Evaluators record interpretation calls without approval pauses** — Moved from blocking progress on each interpretation decision to having evaluators make calls themselves and record them in the exemption-scope file, surfacing mismatches at handoff time.

- **Fix IS scripts to work through symlinked paths** — Scripts compared file paths inconsistently (typed vs. resolved), causing silent failures. Using `realpathSync` on both sides fixes the issue.

- **Add `--instance-id` flag to filter-traces** — Narrows filtering to spans from a single OpenTelemetry SDK run, handling cases where the same service runs concurrently in multiple sessions.

- **Add `--redact-attribute` flag to filter-traces** — Replaces values of named attributes with `REDACTED` everywhere they appear (resources, scopes, spans, events, links), handling personal-data fields like commit author names.

- **Validate filter-traces argument parsing strictly** — Reject option flags used as values and empty strings, preventing invalid input from being silently accepted.

- **Record agent model, effort setting, and spiny-orb commit in every evaluation run** — No earlier run recorded which model it used, making it impossible to determine whether differences came from model changes or other factors. Recording in `run-summary.md` prevents future ambiguity.

- **Treat agent model change as a confound in baseline comparison** — One run cannot separate a model effect from run-to-run variance. Differences from the model are labeled as observations to confirm rather than conclusions. Use attempt and token counts instead of dollar cost for efficiency comparison, since Opus and Sonnet are priced differently.

- **Add watch item for gen_ai.* attributes on LLM-wrapper spans** — Run-28 recorded these attributes; spiny-orb's prompt hasn't changed, so any change in their presence is a sharp candidate signal of a model effect.

- **Make commit-story-v2 run-29 the first model-change evaluation run** — Commit-story-v2's 28 earlier runs provide the best-known run-to-run noise baseline, allowing model effects to be distinguished from variance. Stays a regular run to keep overhead minimal.

- **Reorder Short-term roadmap to prioritize model-change runs** — Commit-story-v2 run-29 moved to first position, release-it run-6 to second, with model-recording cascaded across all active evaluation PRDs.
