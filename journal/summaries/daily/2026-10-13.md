## Key Decisions

- **Prefix the instrument command with a working directory change** — The first run-29 launch ran from the eval repo, causing spiny-orb to load the wrong config and fail before processing files. Commands that depend on working directory should set it explicitly with `cd ~/Documents/Repositories/commit-story-v2 &&` and error handling via `set -o pipefail`.

- **Record the agent model from the log's cost line** — The log's `Total cost` line prints the model ID (e.g., `$9.94 (claude-opus-5-5)`), making historical models recoverable from logs. Only the effort level remains absent.

- **NDS-003 defined-value guard pattern lacks optional-chaining support** — The pattern matches `\w+(?:\.\w+)*` which excludes `?.`, even though the truthy-guard pattern was updated to accept it. Guards like `result.usage_metadata != null` pass while `result.response_metadata?.model != null` fails, despite both correctly wrapping only instrumentation. This is a validator false positive.

- **NDS-003 line numbers refer to stripped, normalized text invisible to the agent** — Error line numbers come from code after OTel stripping, multiline normalization, and Prettier formatting—text that exists only inside the validator. The quoted line in the error is the usable part for agent navigation.

- **No deterministic fixer modified the optional-chained guard lines** — The debug dump represents post-fixer code, and replaying the fixers produces identical output. The optional-chained guard is the agent's own code.

- **NDS-005 false positive from asymmetric normalization in reassembly validation** — The reassembly path normalizes through Prettier but compares against the unformatted original. Prettier re-wrapping changed the try block anchor, causing NDS-005 to report the block as missing. The committed code is byte-identical to the flagged reassembly.

- **Score index.js as full commit of both spans, not partial** — Because every function passed individual validation, the reassembled code is the same code committed. The NDS-005 failure is a validator false positive, not a defect in the agent's instrumentation.

- **Agents generalized NDS-003 guard rejections into avoiding all if-guards** — Some agents concluded that any if statement added to wrap setAttribute would be rejected, causing them to drop attributes entirely. The generalization is broader than the rule's actual behavior; plain `x != null` guards pass.

- **Function-level fallback commits are Prettier-reformatted throughout** — Files committed through fallback are reformatted in their entirety, not only in instrumented functions. This is a formatting-only change but inflates PR diffs.

- **Attempt counts undercount files committed through function-level fallback** — The log's attempt count omits the function-level pass. Three files used three whole-file attempts then committed through a fourth function-level pass.

- **SCH-002 rejections increased significantly in run-29** — Committed files logged 55 SCH-002 rejections versus run-28's 8. This is an observation from one run to confirm in later runs, not a model attribution.

- **context-integrator.js sets vcs.ref.head.revision only to input ref** — The committed code sets only the input ref (defaulting to `HEAD`) without the planned override to the resolved commit hash.

- **Document the per-file evaluation agent prompt as a reusable template** — Batch 1 prompts existed only in session context and needed capture for later batches. The template must be self-contained so subsequent batches can be spawned without prior session memory.

- **Establish CDQ-006 comparability guidance for run-29 vs run-28** — Run-29 scores CDQ-006 with no entry-point exemption, unlike run-28. Run-28 applied it inconsistently because it was never written down. Affected run-28 rows will show as run-29 FAILs due to scoring change, not regression.

- **Make the batch handoff self-contained by pointing to the template** — Updated the milestone to point to `per-file-agent-prompt.md` as the single source of truth, so the next session can start batch 2 from the PRD alone.
